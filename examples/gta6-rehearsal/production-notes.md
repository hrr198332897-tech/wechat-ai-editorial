# 《GTA 6》图文制作记录

## 写作

从 Rockstar 发售公告和 Take-Two 首发记录确认日期与平台。用 Rockstar 的地点、电台资料和 Rob Nelson 的直接采访补充制作细节，再核对 Google 在同周发布的 Genie 4 说明。原始出处保留在稿件末尾。

从 `generate_article.py` 提取并填充文章提示模板，采用其主题、受众、篇幅、大纲和网页资料字段。正文按其倒金字塔要求开头，以假设场景代入，之后分段解释、加入可验证的例子及读者观察方法。本次由 Codex 使用模板写作，并用本地 WeWrite 做稿件检查。 [参考仓库](https://github.com/gzlliyu/generate_article/blob/ff6179856139d737732920bf88dd9e60170f8d9f/generate_article.py)

## 两张图

两张均用内置 ImageGen 生成。主题是原创海滨城市，构图和素材与游戏官方截图、地图与角色分开。文章正文已注明「AI 生成概念图」。

- [首图](cover.png)的提示围绕蓝调时刻的原创海滨城市、S 形跨海桥、车灯、水面与粉橙色天空，采用 2:1 横幅和冷暖反差，适配手机首屏。
- [正文图](street.png)的提示围绕雨后街角、自行车、街灯、橱窗和远处行人，采用路人视角的 16:9 横幅，用来说明街区的空间层次。

## 排版

用 `gzh-content-skill` 的组件库排正文。420 像素宽的[本地预览](layout.html)确认两张图片和九个来源链接完整显示。秀米匿名编辑器的普通粘贴会移除本地图片，随后按 Skill 的无保存 HTML 演练方式将正文和两张内嵌图片放到编辑画布并读回核对。该画布演练未使用账号图库、云端保存或公众号发布。 [秀米实拍](xiumi-editor.png)
