# 英伟达稿公众号交接复盘

2026 年 11 月 24 日。此例验证已选定的新闻进入写作、审核、可复制排版和人工终审交接。归档的版本标题为「离任11天，黄仁勋全票回归！英伟达收涨31.48%」。

| 环节 | 本轮结果 |
| --- | --- |
| 选题 | 用户指定黄仁勋回归与股价上涨 |
| 取证 | 以辞任、拒绝、复职生效、正式公告及后续问询串联日期。股票开盘和收盘保留各自口径，对 X 反应在证据表保留原帖地址与可读旁证 |
| 写作修订 | 从财报说明转为五天内董事会立场变化。保留短句和手机段间留白 |
| 素材 | 独立封面、官方公告标题截图、五节点过程图、前收盘至开盘行情图。按正文顺序嵌入 |
| 富文本复制 | 本轮在独立本地页面实际粘贴，收到 HTML、纯文本、四张图与三个二级标题，单独复制总标题和摘要。随后把原文链接和封面补成独立控件 |
| 秀米 | 较早版本通过 Word 导入、等转换完成、设置标题摘要和封面后保存，重开核对。此项与新版公众号交接分开 |
| 公众号官网接口 | 用图注修订前的稿件、模拟接口返回完成取凭据、四图转存、永久封面、建草稿、回读。[历史离线回执](dry-run.json) 标明了当时的稿件版本及是否创建实号草稿 |
| 人工终审 | 用户确认流程可用。最终发布状态由运营者核实 |

手机端反馈指出公告图注的「截取标题」像制作备注。当前归档和审稿页已改为「英伟达 11 月 23 日发布的复职公告」。制作方式保留在证据文件。

## 在干净目录重建

在仓库根目录使用已按 [安装指南](../../WEWRITE.md) 配置的虚拟环境。下面的命令只读取仓库内的终稿和素材。

```powershell
$nvidiaSource = 'https://nvidianews.nvidia.com/news/nvidia-board-reinstates-jensen-huang-as-president-ceo-and-board-director'
python -X utf8 wechat_handoff.py examples/nvidia-2026-11-24/article.md --summary '离任11天，黄仁勋全票复职。董事会五天内改口，英伟达收涨31.48%。' --author '信号之外' --cover images/cover.jpg --source-url $nvidiaSource --out exports/nvidia-2026-11-24/wechat
```

用浏览器打开输出的 `review.html`。复制正文后，把标题、摘要、作者、原文链接和封面分别填入最终编辑页。选择原文链接时，以支撑主线的英伟达复职公告为准。封面确定为带绿色「+31.48%」的 JPG，裁切时保留人脸和涨幅。原始材料、检查记录与图片归属见 [证据](evidence.md)、[终审记录](article.check.md) 和 [标题及元数据](titles.md)。
