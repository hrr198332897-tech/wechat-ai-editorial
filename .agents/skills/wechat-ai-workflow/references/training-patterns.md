# 信号之外的科技稿训练归纳

依据用户提供的《10篇文章.docx》和《11-article-analysis.docx》。报告索引有 11 个样本，9 篇有全文，样本 1、2 只有标题。样本 3 的图为文字占位。样本里的数字、排名和结论在新稿中须各自溯源。

## 根据新闻类型组织材料

| 类型 | 写作顺序 | 终审要问 |
| --- | --- | --- |
| 技术突破 | 新增结果 → 原先卡在哪里 → 普通人能懂的关键步骤 → 谁用什么验证 → 下一个节点 | 声明、可复现核验、同行理解分别走到哪一步？ |
| 模型或工具发布 | 一个能看到交付物的任务 → 与上一版或竞品的同口径对照 → 效果、耗时、成本及局限 | 演示证明的是哪一次任务？跑分是否对应同一套设置？ |
| 产品争议 | 具体失败任务 → 与之相关的正向证据 → 几个有出处的可能原因 → 什么场景可继续用 | 案例、原因推断和普遍结论是否分得清？ |
| 人物或公司续报 | 新声明或新行动 → 与前一版相比的变化 → 相关方与可追踪的后续 | 暂缓传闻，交代条件；同一事件的旧背景只留解释变化所需的一句。 |
| 商业资本 | 材料里最有解释力的数字 → 单位、时点和口径 → 钱的去向和各方利益 → 读者能跟踪的指标 | 发行、估值、现金流、合同承诺和预测是否分别归类？ |

## 从证据取标题和图片

- 按一个读者能转述的发现出标题。可用数字、时间、人物、竞争差距或条件，但题面须保留影响结论的限定词。首屏兑现。数字无法同口径比较时，换成有出处的动作或场景。
- 在主张表给关键段落记来源、状态、口径和反例。区分已核实的事实、带归属的说法、编辑推断、仍待确认与来源冲突。发布方的成绩与本次自行实测分别记录。
- 让图片承担一种明确任务：吸引点击、展示证据、压缩数字、播放过程或解释结构。优先复用清楚且可用的官网图与原视频；按图所在段落写一句「该看哪里」。重复标识、相似跑分截图与纯装饰图无需堆叠。原创封面标明概念图，字和主体在手机列表仍可辨认。
- 减少套话的最快办法是把模糊形容换成一项具体发现，例如「社区把证明的题面与 Mathlib 标准题面对照」比「迎来历史性突破」信息更多。标题和语气可以强，证据状态决定措辞强度。
